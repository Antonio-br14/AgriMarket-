Coherencia: las pantallas de esta maquetación replican la estructura, los colores y los componentes del prototipo de Figma y del prototipo funcional de la Actividad 4. El objetivo de esta fase es validar la estructura visual y la navegación, no la lógica de negocio completa.

Cómo abrir la maquetación

  1. Abre web/index.html en un navegador moderno (Edge, Chrome o Firefox).
  2. Navega con el encabezado o con las tarjetas de esta página.
  3. Prueba el flujo completo: catálogo → detalle → solicitud → confirmación.
  4. Prueba el flujo del productor: login como productor → panel → publicar producto.
  5. Revisa la versión móvil reduciendo la ventana a 390–500 px de ancho.
